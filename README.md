# DeepLearning-Classifier
Contiene aplicaciones relacionadas con la clasificación mediante aprendizaje profundo (Deep Learning). Las dos aplicaciones realizan la clasificación utilizando diferentes modelos entrenados. Las aplicaciones son las siguientes:

1. CatDogTraining-1: Aplicación de clasificación mediante aprendizaje profundo. Para ejecutar el código, es necesario instalar las bibliotecas tensorflow y pillow. Estas bibliotecas no se incluyen en el repositorio debido a su gran tamaño.
Los modelos utilizados en la clasificación se muestran en las imágenes CatDogTraining-Model-Image-1.jpeg y CatDogTraining-Model-Image-2.jpeg.

2. CatDogTraining-2: Aplicación de clasificación mediante aprendizaje profundo. Para ejecutar el código, es necesario instalar las bibliotecas tensorflow, pandas y opencv-python. Estas bibliotecas no se incluyen en el repositorio debido a su gran tamaño.
Los modelos utilizados en la clasificación se muestran en las imágenes CatDog-Model-Image-1.jpeg y CatDog-Model-Image-2.jpeg.

Lenguaje de programación: Python

IDE: PyCharm, Thonny

Versión: Python3

Módulos: Para instalar los módulos de Python necesarios para los ejemplos, debe consultar la documentación de Python correspondiente al IDE seleccionado.

Sistema operativo: Windows, Linux
